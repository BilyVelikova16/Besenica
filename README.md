# 🪄 Hangman's Wand(Besenica)

## A simple two-player word guessing game written in Python!
Player 1 sets a secret word, and Player 2 tries to guess it one letter at a time before running out of attempts.

### 🎮 Game Rules

1. Two players are required:

   * Player 1 enters a secret word (hidden from Player 2).

   * Player 2 guesses the word letter by letter.

2. Player 2 can make up to 15 incorrect guesses.

3. Each correct guess reveals all instances of that letter in the secret word.

4. If Player 2 reveals all the letters before using up all attempts — they win!

5. If Player 2 uses all 15 wrong guesses — they lose, and the secret word is revealed.

### 🧩 How to Play

1. Make sure you have **Python 3** installed.
2. Open a text editor (like Notepad, VS Code, or Sublime Text).
3. Copy the Hangman Python code into a new file.
4. Save it as `hangman.py`.
5. Open your terminal or command prompt.
 * Windows:Press Win + R, type cmd, then press Enter OR open PowerShell.

 * Mac:Open Terminal (from Applications → Utilities → Terminal).
 * Linux:Open your preferred terminal (Ctrl + Alt + T usually works).

6. Navigate to the folder where you saved the file.
7. Run the game
8. Follow the instructions and enjoy!
